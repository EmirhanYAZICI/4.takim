# Keywords

Dart'ta anahtar kelimeler.

Aşağıdaki tablo, Dart dilinin kendi kullanımı için ayırdığı (rezerve ettiği) kelimeleri listeler. Aksi belirtilmedikçe bu kelimeler tanımlayıcı (identifier) olarak kullanılamaz. İzin verildiği durumlarda bile anahtar kelimeleri tanımlayıcı olarak kullanmak, kodunuzu okuyan diğer geliştiricilerin kafasını karıştırabilir ve bundan kaçınılmalıdır. Tanımlayıcı kullanımı hakkında daha fazla bilgi edinmek için ilgili terime tıklayın.

|                        |                         |                       |                       |
|------------------------|-------------------------|-----------------------|-----------------------|
| abstract <sup>2</sup>  | as <sup>2</sup>         | assert                | async <sup>3</sup>    |
| await <sup>1</sup>     | base <sup>3</sup>       | break                 | case                  |
| catch                  | class                   | const                 | continue              |
| covariant <sup>2</sup> | default                 | deferred <sup>2</sup> | do                    |
| dynamic <sup>2</sup>   | else                    | enum                  | export <sup>2</sup>   |
| extends                | extension <sup>2</sup>  | external <sup>2</sup> | factory <sup>2</sup>  |
| false                  | final (var)             | final (class)         | finally               |
| for                    | Function <sup>2</sup>   | get <sup>2</sup>      | hide <sup>3</sup>     |
| if                     | implements <sup>2</sup> | import <sup>2</sup>   | in                    |
| interface <sup>2</sup> | is                      | late <sup>2</sup>     | library <sup>2</sup>  |
| mixin <sup>2</sup>     | new                     | null                  | of <sup>3</sup>       |
| on <sup>3</sup>        | operator <sup>2</sup>   | part <sup>2</sup>     | required <sup>2</sup> |
| rethrow                | return                  | sealed <sup>3</sup>   | set <sup>2</sup>      |
| show <sup>3</sup>      | static <sup>2</sup>     | super                 | switch                |
| sync <sup>3</sup>      | this                    | throw                 | true                  |
| try                    | type <sup>2</sup>       | typedef <sup>2</sup>  | var                   |
| void                   | when <sup>3</sup>       | with                  | while                 |
| yield <sup>1</sup>     |                         |                       |                       |

<sup>1</sup> Bu anahtar kelime, bağlama göre tanımlayıcı olarak kullanılabilir.

<sup>2</sup> Bu anahtar kelime; bir türün (sınıf, mixin, enum, extension type veya type alias) adı, bir extension'ın adı ya da import öneki olarak kullanılamaz. Diğer tüm durumlarda tanımlayıcı olarak kullanılabilir.

<sup>3</sup> Bu anahtar kelime, herhangi bir kısıtlama olmaksızın tanımlayıcı olarak kullanılabilir.
